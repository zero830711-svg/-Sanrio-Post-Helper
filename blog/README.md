# 商品記事を増やす手順

## 標準REST APIでの登録（推奨・WPVibe不要）

WordPressのプロフィールでアプリケーションパスワードを作成し、GitHubの当リポジトリの Settings → Secrets and variables → Actions に次を保存します。値をチャット、ソースコード、リポジトリ変数に記載しないでください。

|Secret名|値|
|---|---|
|`SANRIO_WP_USER`|WordPressのログインユーザー名|
|`SANRIO_WP_APP_PASSWORD`|新規発行したアプリケーションパスワード（通常のログインパスワードは使用しない）|

Actions → **Sanrio WordPress REST** → Run workflow を開きます。

- `check`：認証・商品紹介カテゴリー・既存記事の重複を確認。書き込みなし。
- `draft`：重複のない商品を画像付きの下書きに登録。
- `publish`：下書きとアイキャッチの保存を検証してから公開。既存の公開記事は変更しません。正規スラッグの既存下書きは再開します。

対象は `products-2026-10-18.json` のレビュー済み５件です。画像はメーカーの確認済みURLから取得し、WordPressのメディアへ保存します。REST APIはサイトを `https://sanrio-fan.site` に固定し、認証ヘッダーの転送を伴うリダイレクトは拒否します。認証情報とサーバーのレスポンス本文はログへ出しません。

プラグイン設置は不要です。追加の定期実行は設定していません。`python3 -m unittest discover -s blog/tests -p test_wordpress_rest.py -v` で重複・再開・公開前検証を確認します。

## Post Helperからの書き出しと任意の取り込みプラグイン

以下は先に準備した任意の取り込み方法です。上の標準REST API方式では設置不要です。

1. Post Helperの楽天商品候補を開き、「ブログ用データを保存」でJSONを保存します。同期キーやAPIキーは出力しません。選択中の紹介リンクはそのまま引き継ぎます。
2. `wordpress` ディレクトリを `sph-product-import` フォルダー名でZIPにし、WordPressのプラグインとしてインストール・有効化します。有効化時に `/product-import/` ページを作ります。
3. WordPressにログインし、商品取り込みページでJSONを選択します。既存の公開記事・下書き・予約・非公開・ゴミ箱をJAN、出典URL、型番＋キャラクターで確認します。
4. 重複のない商品のみ下書きに取り込みます。サーバー側でも再照合し、同一商品の同時取り込みをロックします。既存記事は上書きしません。
5. 編集画面で公式情報を読み直し、画像を使用条件に従って登録してアイキャッチに指定し、リンク・表記を確認して公開します。候補画像は `_sph_candidate_images` メタに保管します。リモート画像の自動ダウンロードはしません。

`products-2026-10-18.json` は公式スケーター商品ページで仕様を確認した５件です。Amazon・楽天はJANを含む検索リンクと明記しています。価格・在庫・未確認の発売日は掲載していません。
